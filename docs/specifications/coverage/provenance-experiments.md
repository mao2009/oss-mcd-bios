# Coverage audit E: source provenance, usage terms and experimental substitutes (PRV-)

Audit area E of the spec-coverage audit. Question asked: can a Mega-CD-compatible BIOS be specified and tested from public, independent material alone, without the original BIOS? This file covers the **sources themselves** (what exists, who owns it, what it allows, whether it is reachable and intact, whether it is independent), the **legal, independent experiments** that could replace missing sources, and **clean-room process options** for the BIOS API.

> [!IMPORTANT]
> **No legal conclusions are given here.** Every "may read / may paraphrase / never copy" column states what the licence text or marking *says* and what the project policy ([provenance.md](../../provenance.md)) asks. Whether a use is lawful in a given jurisdiction is flagged **LEGAL-REVIEW** for the maintainer or counsel. Issue #17 (CONFIDENTIAL-marked material) is still open. Here, CONFIDENTIAL/PROPERTY-OF-SEGA material is recorded as existing, with its usage question, and is **excluded** whenever we judge "implementable from public material only".

Audit date: 2026-10-08. Base: `origin/agent-a/issue-1-rom-layout` @ `c2abc36` (PR #16). Labels CONFIRMED / ESTIMATED / UNCONFIRMED follow [../README.md](../README.md). Levels: **LA** = minimal BIOS boot, **LB** = boot a homebrew CD program, **LC** = commercial-game-compatible BIOS.

Nothing was copied from any source into this file. Clones were shallow, read-only, and kept in a scratch directory outside the repository. No Sega BIOS binary, dump or disassembly was obtained or read. The commercial-game boot data `base.img` offered by I-RHOPE was **not** downloaded. The byte data in MegaDev `lib/security.c` was **not** read, decoded or reproduced; only its file structure (comment header, `#if REGION` blocks, line counts) was inspected so that it could be classified.
