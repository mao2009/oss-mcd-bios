# Original implementation / provenance rules

The project aims to distribute an original replacement BIOS, **not Sega-owned ROM code or assets**.

1. Do not commit, attach or redistribute proprietary BIOS ROMs, extracted graphics, audio, binary patches derived from copyrighted ROMs, or verbatim disassembly.
2. Prefer public hardware documentation, original experiments, synthetic fixtures and independently written code. Document citations and provenance for implementation decisions.
3. If reference BIOS behavior must be observed, write clean-room behavior specifications and independent tests. Keep reference binaries outside the project and outside CI.
4. Record contributor acknowledgements, relevant permissions and licensing for borrowed third-party code. MIT-compatible licensing must be confirmed before integration.
5. Do not promise that clean-room development eliminates all legal risks; regional laws, patents, trademarks and distribution rights may require review.
6. The project is not affiliated with or endorsed by Sega. Trademarks belong to their owners.

When provenance is uncertain, open an issue and **do not merge the contribution** until it is resolved.
