# Genesis Plus GX smoke harness (external, test-only)

Boots a BIOS ROM headless on a **pinned** Genesis Plus GX libretro core and emits a result JSON.
Host tooling only: nothing here is linked into, or required by, the BIOS ROM.

> **License boundary.** Genesis Plus GX is under a **non-commercial** license, not MIT.
> Only its URL and commit SHA live here ([`gpgx.lock`](gpgx.lock)). Source and built core go to the
> git-ignored `tools/emu/.cache/` and must never be committed, released or uploaded as CI artifacts.
> Findings and citations: [docs/emulator/gpgx-investigation.md](../../docs/emulator/gpgx-investigation.md).

Requirements: Python 3.9+ (stdlib only), git, a C compiler and make
(Windows: MinGW-w64 GCC + `mingw32-make`; Linux: `gcc` + `make`).

```sh
python -I tools/emu/gpgx_harness.py fetch                       # clone + build at the pin (~25 s)
python -I tools/emu/gpgx_harness.py make-fixture /tmp/fixture.bin
python -I tools/emu/gpgx_harness.py run --rom /tmp/fixture.bin \
    --expect main:FF0000=4F4B4F4B --frames 120 --out result.json
python -I tools/emu/test_gpgx_harness.py                        # unit tests (emulator mocked)
```

`--expect SPACE:ADDR=HEXBYTES` asserts memory after the last frame, in 68000 byte order:
`main` = main-CPU work RAM `$FF0000-$FFFFFF`, `prg` = sub-CPU PRG-RAM `$000000-$07FFFF`.
`--region auto|ntsc-u|pal|ntsc-j` overrides region detection.

## Result

```json
{"status": "PASS|FAIL|SKIP|BLOCKED", "rom_sha256": "...", "emulator_sha": "...",
 "command": "...", "trace": {"samples": [...], "core_log": [...], "checks": [...], "stage": "..."},
 "reason": "..."}
```

| Status | Meaning | Exit |
| --- | --- | --- |
| PASS | Core loaded the ROM in Mega-CD mode and **every** `--expect` held | 0 |
| FAIL | Host crashed/timed out, core rejected the ROM, not in Mega-CD mode, or an assertion failed | 1 |
| SKIP | Pinned core not built (run `fetch`) | 3 |
| BLOCKED | ROM missing / fails loader preconditions, checkout not at the pin, bad `--expect`, or no `--expect` given | 4 |

There is no PASS without a checkpoint assertion. ROM preconditions (from the pinned loader): `BR` at
header `$180`, no `C` in I/O support `$190`, ≤ 8MB; a size other than 128KB is only a warning.

The fixture ROM is generated by `make-fixture` (hand-assembled, original, 128KB) and is not committed.
