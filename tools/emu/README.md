# Genesis Plus GX smoke harness (external, test-only)

Boots a BIOS ROM headless on a **pinned** Genesis Plus GX libretro core and emits one evidence record
(`tools/evidence/result.schema.json`, schema_version 1). Host tooling only.

**No emulator-specific code goes into the BIOS.** The ROM bytes are used unchanged. The default
`--mode system` installs the ROM as the emulator's system-directory BIOS file, so the ROM header
does not have to satisfy any emulator rule.

> **License boundary.** Genesis Plus GX is under a **non-commercial** license, not MIT.
> Only its URL and commit SHA live here ([`gpgx.lock`](gpgx.lock)). Source and built core go to a
> cache **outside the repository** (`$GPGX_CACHE_DIR`, default `%LOCALAPPDATA%\oss-mcd-bios\gpgx` on
> Windows, `${XDG_CACHE_HOME:-~/.cache}/oss-mcd-bios/gpgx` elsewhere). They must never be committed,
> released or uploaded as CI artifacts.
> Findings and citations: [docs/emulator/gpgx-investigation.md](../../docs/emulator/gpgx-investigation.md).

Requirements: Python 3.9+ (stdlib only), git, a C compiler and make
(Windows: MinGW-w64 GCC + `mingw32-make`; Linux: `gcc` + `make`).

```sh
python -I tools/emu/gpgx_harness.py fetch                       # clone + build at the pin (~25 s)
python -I tools/emu/gpgx_harness.py version                     # exit 0 = built core is at the pin
python -I tools/emu/gpgx_harness.py make-fixture /tmp/fixture.bin
python -I tools/emu/gpgx_harness.py run --rom /tmp/fixture.bin \
    --expect main:FF0000=4F4B4F4B --frames 120 --out result.json
python -I tools/emu/test_gpgx_harness.py                        # unit tests (emulator mocked)
```

| Option | Meaning |
| --- | --- |
| `--mode system` (default) | ROM copied unchanged to `bios_CD_{U,E,J}.bin` in a temporary system directory. A data-less synthetic disc image (only the `SEGADISCSYSTEM` ID) is inserted so the core enters Mega-CD mode. |
| `--mode bootrom` | ROM loaded as content. **Emulator-specific:** the core only maps it as BOOT ROM if the header has `BR` at `$180` and no `C` at `$190`. Otherwise the result is BLOCKED. |
| `--expect SPACE:ADDR=HEX` | Asserts memory after the last frame, in 68000 byte order: `main` covers `$FF0000-$FFFFFF`, `prg` covers sub-CPU PRG-RAM `$000000-$07FFFF`. Out-of-range addresses are rejected. |
| `--region` | `auto`, `ntsc-u`, `pal` or `ntsc-j`. |
| `--rom-commit` | Git commit the ROM was built from. Recorded as-is. |

## Status

| Status | Meaning | Exit |
| --- | --- | --- |
| PASS | Requires `--expect` (checkpoint `startup`). Every assertion held, **and** each expected value differs from the power-on RAM snapshot, so a BIOS that does nothing cannot pass. **A run without `--expect` is never PASS:** loading the BIOS is not boot success. | 0 |
| FAIL | The host crashed or timed out, the core rejected the content, the core did not enter Mega-CD mode, or an assertion failed. | 1 |
| SKIP | The pinned core is not built (run `fetch`). | 3 |
| BLOCKED | The ROM or lock is missing, `--mode bootrom` preconditions are unmet, the checkout is not at the pin, an `--expect` is bad, or no `--expect` was given (checkpoint `bios-loaded`). | 4 |

The record keeps no absolute paths. `observed.command` uses placeholders, and `log_excerpt` is path-redacted and truncated.
The fixture ROM is generated by `make-fixture` (hand-assembled, original, 128KB) and is not committed.
